## Angle library — 20 angles

| Key | Label | What it does |
| --- | --- | --- |
| `problem-agitation` | Problem / agitation | Names the pain and turns up the heat before offering relief. |
| `mechanism` | Unique mechanism | Explains the specific "how" that makes the product work — the classic differentiator. |
| `authority-science` | Authority / science | Borrows credibility from experts, studies, labs or certifications. |
| `social-proof` | Social proof | Leans on crowds, ratings and testimonials to de-risk the purchase. |
| `transformation` | Transformation / before-after | Sells the visible change and the timeline to get it. |
| `founder-story` | Founder / origin story | Uses a personal origin narrative to build trust and differentiation. |
| `us-vs-them` | Us vs. them | Positions against an enemy — competitors, the old way, or an industry. |
| `curiosity` | Curiosity / open loop | Withholds the payoff to buy the click. |
| `urgency-scarcity` | Urgency / scarcity | Compresses the decision window with deadlines or stock limits. |
| `offer-value` | Offer / price-value | Leads with the deal rather than the product. |
| `risk-reversal` | Risk reversal / guarantee | Removes the downside of trying. |
| `identity` | Identity / tribal call-out | Speaks to a specific self-image so the right reader self-selects. |
| `fear-warning` | Fear / warning | Frames inaction as the dangerous choice. |
| `convenience` | Convenience / simplicity | Sells the absence of effort. |
| `clean-natural` | Clean / natural ingredients | Differentiates on what is NOT in the product. |
| `aspiration` | Aspiration / status | Sells the identity upgrade rather than the function. |
| `objection-handling` | Objection handling | Pre-empts the reason the reader would say no. |
| `seasonal-event` | Seasonal / event hook | Attaches the offer to a date on the reader's calendar. |
| `ingredient-hero` | Hero ingredient | Leads with one named ingredient as the reason to believe. |
| `ugc-testimonial` | Customer voice / UGC | Written as a customer speaking, not a brand broadcasting. |
